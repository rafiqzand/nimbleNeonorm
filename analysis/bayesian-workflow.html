A Bayesian workflow with nimbleNeonorm

This vignette fits a skewed location-scale model with the MSNBurr and MSNBurr-IIa distributions, following the steps of the Bayesian workflow of Gelman et al. (2020): specify the model and its priors, check the priors through the data they imply, validate the computation on simulated data with known parameters, check convergence, check the fit against the data, and compare models.

library(nimbleNeonorm)
register_neonorm(verbose = FALSE)

1. The distributions

Both distributions have a location mu, a scale sigma and a shape alpha (Choir, 2020; Ramadani et al., 2025). Their mode is mu, where the density equals that of a normal distribution with standard deviation sigma. With alpha = 1 both are symmetric. MSNBurr is skewed to the left for alpha < 1 and to the right for alpha > 1; MSNBurr-IIa, its mirror image about mu, does the opposite.

x <- seq(-5, 5, length.out = 401)
dens <- function(f, a) vapply(x, f, numeric(1), mu = 0, sigma = 1, alpha = a)
alphas <- c(0.3, 1, 3)

op <- par(mfrow = c(1, 2), mar = c(4, 4, 2, 1))
for (fam in c("MSNBurr", "MSNBurr-IIa")) {
  f <- if (fam == "MSNBurr") dmsnburr else dmsnburr2a
  plot(x, dnorm(x), type = "l", lty = 2, ylim = c(0, 0.6),
       xlab = "x", ylab = "density", main = fam)
  for (k in seq_along(alphas)) lines(x, dens(f, alphas[k]), col = k + 1)
  legend("topright", c("normal", paste("alpha =", alphas)),
         lty = c(2, 1, 1, 1), col = c(1, 2:4), bty = "n", cex = 0.8)
}

par(op)

2. Model and priors

We model N observations as independent draws from MSNBurr-IIa. The priors are weakly informative for data on a unit scale, so the data should be standardised (or the priors rescaled) before fitting:

  • mu ~ Normal(0, 5): the location lies within a few units of zero.
  • sigma ~ Exponential(1): a proper prior on the scale that favours moderate values without excluding large ones (Gelman, 2006).
  • alpha ~ LogNormal(0, 1): its median, 1, is the symmetric case, and it treats skewness in either direction alike on the log scale; 95% of its mass lies between about 0.14 and 7.1.
model_code <- list(
  normal = nimbleCode({
    for (i in 1:N) y[i] ~ dnorm(mu, sd = sigma)
    mu ~ dnorm(0, sd = 5)
    sigma ~ dexp(1)
  }),
  msnburr = nimbleCode({
    for (i in 1:N) y[i] ~ dmsnburr(mu, sigma, alpha)
    mu ~ dnorm(0, sd = 5)
    sigma ~ dexp(1)
    alpha ~ dlnorm(0, sdlog = 1)
  }),
  msnburr2a = nimbleCode({
    for (i in 1:N) y[i] ~ dmsnburr2a(mu, sigma, alpha)
    mu ~ dnorm(0, sd = 5)
    sigma ~ dexp(1)
    alpha ~ dlnorm(0, sdlog = 1)
  })
)

make_model <- function(family, y) {
  inits <- list(mu = 0, sigma = 1)
  if (family != "normal") inits$alpha <- 1
  nimbleModel(
    model_code[[family]],
    constants = list(N = length(y)),
    data = list(y = y),
    inits = inits
  )
}

3. Prior predictive check

Before looking at any data, we simulate parameters from the priors and data from the likelihood, and ask whether the implied data are plausible (Gelman et al., 2020, Section 2.4; Gabry et al., 2019).

n <- 200

# Spread of each simulated data set

summary(prior_range)
#>     Min.  1st Qu.   Median     Mean  3rd Qu.     Max. 
#>  0.00402  2.09555  4.67753  6.94517  9.85917 44.85661

hist(prior$data[1:20, ], breaks = 60, main = "Prior predictive data",
     xlab = "y (20 simulated data sets)")

For standardised data, most simulated data sets should span a few to a few tens of units, with only a small fraction far more extreme. If many simulated data sets were implausible for the application, the priors would need to be tightened before fitting; if they were all nearly identical, the priors would be too restrictive.

4. Validating the computation on simulated data

To check that the model and the software recover known parameters, we simulate data with known values and fit the model to them (Cook et al., 2006; Gelman et al., 2020, Section 4.1).

true <- c(mu = 0, sigma = 1, alpha = 0.3)   # clearly right-skewed
set.seed(2026)
y <- replicate(n, rmsnburr2a(1, true[["mu"]], true[["sigma"]],
                             true[["alpha"]]))

fit <- runmcmc_neonorm(
  make_model("msnburr2a", y),
  niter = 4000,
  nchains = 4,

runmcmc_neonorm() starts the four chains from different draws of the prior (prior_inits_neonorm()), so that \(\hat{R}\) can detect chains that have not mixed. The slice sampler is used for alpha because it needs no proposal scale (Neal, 2003).

recovery <- cbind(true = true,
                  fit$summary[names(true), c("Mean", "2.5%", "97.5%")])
round(recovery, 3)
#>       true   Mean   2.5% 97.5%
#> mu     0.0 -0.093 -0.307 0.127
#> sigma  1.0  0.989  0.876 1.120
#> alpha  0.3  0.368  0.243 0.538

The true values should lie inside their 95% credible intervals, and the posterior means should be close to them. A single data set is only a sanity check, since a 95% interval misses the truth 5% of the time; the repeated-simulation study in the package repository (analysis/simulation-study.R) estimates bias, mean squared error and interval coverage over many data sets.

5. Convergence diagnostics

The summary reports the rank-normalised split-\(\hat{R}\) and the bulk and tail effective sample sizes of Vehtari et al. (2021). They recommend \(\hat{R} < 1.01\) and ESS above 100 per chain; summarise_neonorm() warns otherwise. Trace plots complement these numbers.

fit$summary[, c("Rhat", "ESS_bulk", "ESS_tail")]
#>           Rhat  ESS_bulk  ESS_tail
#> alpha 1.002907  984.1834 1867.6526
#> mu    1.003934  691.9576  977.2111
#> sigma 1.002103 1504.7098 1841.7910
coda::traceplot(fit$samples[, "alpha"], main = "alpha")

6. Posterior predictive check

We simulate replicated data sets from the fitted model and compare them with the observed data, both visually and through a test statistic, the sample skewness (Gelman et al., 2013, Chapter 6; Gabry et al., 2019).

yrep <- posterior_predict_neonorm(fit, ndraws = 200, seed = 1)

plot(density(y), lwd = 2, main = "Observed (black) vs replicated (grey)",
     xlab = "y")
for (i in 1:50) lines(density(yrep[i, ]), col = grDevices::gray(0.6, 0.4))
lines(density(y), lwd = 2)


skewness <- function(v) mean((v - mean(v))^3) / stats::sd(v)^3
t_obs <- skewness(y)
t_rep <- apply(yrep, 1, skewness)
hist(t_rep, breaks = 30, main = "Skewness of replicated data",
     xlab = "sample skewness")
abline(v = t_obs, lwd = 2)

mean(t_rep >= t_obs)   # posterior predictive p-value
#> [1] 0.59

A posterior predictive p-value far from 0 and 1 means the model reproduces the skewness of the data.

7. Model comparison

Finally, we fit the normal and MSNBurr models to the same data and compare the three with WAIC (Watanabe, 2010; Vehtari et al., 2017); lower is better.

fits <- list(
  normal = runmcmc_neonorm(make_model("normal", y), niter = 4000,
                           WAIC = TRUE),
  msnburr = runmcmc_neonorm(make_model("msnburr", y), niter = 4000,
                            sampler = "slice", WAIC = TRUE),
  msnburr2a = fit
)
